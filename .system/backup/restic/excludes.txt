# The paths and patterns that the hourly restic backup skips.
#
# 95-restic.sh copies this file to /etc/restic/excludes.txt one time and does
# not change it after that. Edit the copy in /etc/restic.
#
# Write one pattern on each line. restic ignores empty lines and lines that
# start with #. A pattern without a leading / matches at any depth.
#
# restic also skips each folder that has a CACHEDIR.TAG file, for example the
# target folders of Rust projects. It also skips each folder that has a
# .nobackup file. To skip a folder without a change to this file, run
# "touch <folder>/.nobackup".
